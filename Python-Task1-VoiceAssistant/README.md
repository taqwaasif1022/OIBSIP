# Apex AI — Advanced Voice Assistant

A Python-based AI voice assistant developed for the **Oasis Infobyte Python Programming Internship — Task 1**.

## Features

- 🎙️ Voice input using SpeechRecognition
- 🔊 Text-to-speech responses using pyttsx3
- 👋 Natural conversational interaction
- 🧠 AI-powered responses using Google Gemini
- 🔎 Web research using Tavily and DuckDuckGo
- 📰 News search
- 🌦️ Weather information
- 🕐 Current time and date
- 🧮 Mathematical calculations
- 🌐 Web search and website-opening commands
- 🗣️ Natural-language command handling
- ⚠️ Error handling for unsuccessful voice recognition and external requests

## Technologies

- Python
- Google Gemini
- LangChain
- SpeechRecognition
- pyttsx3
- Tavily
- DuckDuckGo Search
- python-dotenv
